# v9.7.0 Reproduction & Replication Workflow Map

Scientific Results Synthesis (v9.6)
→ Target binding
→ Reproduction or replication mode
→ Environment capture
→ Input/artifact capture
→ Invariants and planned changes
→ Researcher-defined comparison criteria
→ Plan-only execution specification
→ Explicit execution through existing Workbench runtime
→ Observed result comparison
→ Discrepancy report + researcher assessment
→ Platform Core reproduction/replication binding plan

The workflow preserves provenance and comparison state but does not infer a scientific replication verdict.
