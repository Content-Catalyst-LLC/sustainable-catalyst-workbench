# Workbench v9.12.0 — Workbench v9 Production Certification

v9.12.0 closes the Workbench v9 line with an operational/software production certification layer.

The certification audits canonical release identity, runtime health/readiness, persistent-store writability, all retained v9.0–v9.11 milestone manifests and primary capability flags, research-package portability, platform-wide handoff, end-to-end research-study certification, Platform Core non-dispatch boundaries, WordPress release identity, deployment invariants, and public API readiness.

Production certification does **not** certify scientific validity, evidence truth, causal correctness, statistical merit, peer-review acceptance, or publication merit. No remediation, Core dispatch, or governed Core persistence occurs automatically.
