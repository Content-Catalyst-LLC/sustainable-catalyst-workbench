# Workbench v8.8.0 — Comparative Experiment & Model Analysis

Workbench v8.8.0 adds neutral side-by-side comparison of completed execution jobs. It extracts bounded numeric request/result metrics, builds metric matrices, supports baseline or all-pairs comparisons, and calculates transparent numeric deltas only when both jobs expose the same scalar metric.

## Boundaries
- No automatic winner/model ranking.
- No scientific-validity, causality, or statistical-significance inference.
- No mutation of jobs or results.
- Platform Core integration remains explicit plan-only binding.
