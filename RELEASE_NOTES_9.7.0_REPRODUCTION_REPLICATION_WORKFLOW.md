# Workbench v9.7.0 — Reproduction & Replication Workflow

Adds a researcher-controlled reproduction and replication layer over v9.6 scientific results syntheses. Workflows bind an immutable target synthesis, capture environment and input expectations, define comparison criteria, distinguish same-condition reproduction from replication with explicit planned changes, produce plan-only execution specifications, compare observed metrics against declared tolerances, record discrepancies, and prepare a non-dispatching Platform Core binding plan.

## Scientific boundary

A tolerance comparison is not a replication verdict. Workbench does not automatically execute reruns, infer scientific validity, accept or reject hypotheses, infer causality, resolve discrepancies, or create governed replication claims. Researcher assessment remains explicit and Platform Core retains governance authority.
