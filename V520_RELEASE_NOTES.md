# Workbench v5.2.0 — Interactive Graph Mathematics

v5.2.0 connects the governed v5.1 symbolic mathematics engine to interactive graph objects and analysis.

## Added
- Cartesian, parametric, polar, and implicit/contour graph sampling.
- Live bounded parameters for equation ↔ graph updates.
- Symbolic derivative overlays and definite-integral shading data.
- Root, extrema, and intersection analysis across a selected domain.
- Vector-field graph objects with normalized direction rendering.
- 3D surface grids and responsive wireframe rendering.
- Canonical content-hashed graph objects with source, viewport, parameters, and provenance.
- Dedicated WordPress Graph Mathematics studio and shortcodes.

## Boundary
All expressions are parsed by the v5.1 restricted AST/SymPy parser. v5.2 does not authorize arbitrary Python, `eval`, `exec`, remote shell, automatic publication, or automatic high-stakes decisions.
