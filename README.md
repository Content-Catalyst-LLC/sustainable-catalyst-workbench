# Sustainable Catalyst Workbench v8.11.0

Current release: **Workbench v8.11.0 — Research Publication & Evidence Handoff**.

v8.11.0 turns immutable v8.10 analysis-board snapshots into governed publication and evidence handoff packages. It preserves researcher-authored methods, assumptions, findings, notes, figures, comparison provenance, execution/asset hashes, and explicit evidence references while planning non-dispatching transfers to Platform Core, Knowledge Library, Research Lab, and external publication workflows.

The handoff does not publish automatically, generate findings, infer scientific validity, causality or significance, select preferred models, resolve evidence conflicts, or mutate authoritative source objects.

See `RELEASE_NOTES_8.11.0_RESEARCH_PUBLICATION_EVIDENCE_HANDOFF.md`, `V8110_RESEARCH_PUBLICATION_EVIDENCE_HANDOFF_MAP.md`, and `docs/V8110_RESEARCH_PUBLICATION_EVIDENCE_HANDOFF.md`.
