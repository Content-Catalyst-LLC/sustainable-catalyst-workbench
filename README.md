# Sustainable Catalyst Workbench v10.4.0

Current release: **Workbench v10.4.0 — Hyperparameter Optimization & Search Engine**.

v10.4.0 extends the Scientific AI Engineering line with content-addressed hyperparameter search studies backed by v10.2 training-run templates and v10.3 benchmark objectives. It provides typed search spaces, deterministic grid/random/Latin-hypercube trial manifests, explicit external Bayesian/custom optimizer contracts, resource/search budgets, immutable trial results, resumable search state, objective diagnostics, and Platform Core plan-only handoff.

The release does not launch training automatically, call external optimizers or providers, promote a trial/model, approve deployment, infer scientific validity, or automatically create governed Platform Core objects.

See `RELEASE_NOTES_10.4.0_HYPERPARAMETER_OPTIMIZATION_SEARCH_ENGINE.md` and `V1040_HYPERPARAMETER_OPTIMIZATION_SEARCH_ENGINE_MAP.md`.
