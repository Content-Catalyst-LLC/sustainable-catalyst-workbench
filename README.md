# Sustainable Catalyst Workbench v9.6.0

Current release: **Workbench v9.6.0 — Scientific Results & Narrative Synthesis**.

v9.6.0 extends the v9 scientific-study workflow with a reproducible synthesis layer over statistical analyses, uncertainty/sensitivity studies, model calibrations, analysis-board snapshots, and publication/evidence packages. Researchers author narrative statements, methods, results, interpretation, limitations, assumptions, and conclusions; Workbench preserves source hashes, evidence references, statement/source traceability, content addressing, and explicit publication/Core handoff plans.

The synthesis workspace does not invent findings, decide significance, infer causality, accept hypotheses, resolve contradictions, publish automatically, or replace Platform Core governance.

See `RELEASE_NOTES_9.6.0_SCIENTIFIC_RESULTS_NARRATIVE_SYNTHESIS.md`, `V960_SCIENTIFIC_RESULTS_NARRATIVE_SYNTHESIS_MAP.md`, and `docs/V960_SCIENTIFIC_RESULTS_NARRATIVE_SYNTHESIS.md`.
