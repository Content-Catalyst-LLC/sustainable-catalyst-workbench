# Workbench v9.10.0 — Platform-Wide Scientific Research Handoff

## Purpose
Create an immutable, content-addressed handoff envelope over a v9.9 portable research package and translate it into explicit destination contracts across Sustainable Catalyst.

## Destinations
- Platform Core — governed research/evidence/provenance intake planning.
- Knowledge Library — research source and publication intake planning.
- Research Lab — reproducible study/experiment continuation planning.
- Decision Studio — decision-support evidence intake planning.
- External publication — traceable publication/export preparation.
- Archive — long-term portable package preservation.

## Key capabilities
- v9.9 portable package as canonical transport substrate.
- Content-addressed handoff envelopes.
- Per-destination contracts and readiness checks.
- Unresolved destination requirements surfaced explicitly.
- Destination-plan API without automatic dispatch.
- Platform Core governance plan without governed-object creation.
- Immutable persistence and idempotent saves.

## Scientific and governance boundaries
Workbench does not infer scientific validity, promote evidence automatically, publish automatically, recommend decisions, activate imports, or dispatch to any destination automatically. Platform Core remains the governed research/evidence authority.
