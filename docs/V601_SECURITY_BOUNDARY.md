# Workbench v6.0.1 — Security Boundary

v6.0.1 is an interface and runtime-identity hardening release.

It does not add arbitrary code execution, Python eval/exec, remote shell access, autonomous publication, autonomous certification, destructive synchronization, automatic hardware programming, serial-port access, GPIO access, or JTAG access.

Favorites, recent studios, and last-active-studio preferences are browser-local interface state. They do not trigger cloud synchronization or remote actions.
