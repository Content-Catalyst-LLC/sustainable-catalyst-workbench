# Workbench v5.3.3 Security Boundary

v5.3.3 changes WordPress/browser presentation and navigation behavior only. It does not expand execution authority.

- FastAPI computational runtime remains v5.3.0.
- Restricted symbolic parsing remains unchanged.
- No arbitrary Python, shell, remote command, automatic publication, automatic device programming, or unattended hardware execution is authorized.
- The homepage scroll guard is a browser-interface constraint and does not alter backend permissions.
