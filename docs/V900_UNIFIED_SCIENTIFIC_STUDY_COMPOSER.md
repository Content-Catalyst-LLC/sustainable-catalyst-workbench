# Unified Scientific Study Composer

Workbench v9.0.0 makes the scientific study the top-level computational research object. It composes existing authoritative Workbench records and explicit researcher narrative into a reproducible study view. It does not mutate those source objects, adjudicate evidence, infer scientific correctness, select a preferred model, accept a hypothesis, infer causality/significance, publish automatically, or dispatch automatically to Platform Core.
