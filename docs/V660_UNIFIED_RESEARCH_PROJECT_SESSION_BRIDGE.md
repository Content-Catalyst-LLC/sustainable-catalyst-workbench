# Workbench v6.6.0 — Unified Research Project & Session Bridge

Workbench v6.6.0 binds canonical Workbench computational projects into Platform Core 3.0 unified research runtime sessions. The lifecycle is two-phase: prepare/persist the Core session first, then bind Workbench product, project, objects, executions, visuals, validations, packages, and handoffs using the Core-issued session id. Workbench does not fabricate Core session IDs or automatically persist Core state.
