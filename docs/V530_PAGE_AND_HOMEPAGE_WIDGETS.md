## Homepage

Use:

```text
[sc_workbench_homepage_instrument]
```

The homepage widget deliberately uses a dark computational-instrument visual language distinct from Site Intelligence, Library, and Lab. It cycles through four conceptual demonstrations:

1. mathematics → graph
2. mathematics → sound
3. mathematics → form
4. mathematics → physical system

It does not use a ticker or photographic treatment.
