# Workbench v6.10.0 — Predictive Intelligence Runtime Integration

v6.10.0 makes Workbench the specialist predictive computation plane for Sustainable Catalyst. It produces deterministic forecast artifacts, backtest evidence, and calibration evidence that can be registered in Platform Core without granting Core execution authority.

Execution remains explicit-input and deterministic for identical inputs. Core-issued identifiers are required for phase-two provenance and visual-predictive bindings.
