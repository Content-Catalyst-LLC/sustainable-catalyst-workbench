# v5.3.1 Homepage Computational Instrument Refinement

`[sc_workbench_homepage_instrument]` remains distinct from the Site Intelligence, Lab, and Library homepage surfaces.

The refined visual hierarchy uses:

- a compact Workbench/runtime header;
- a live mathematical transformation surface;
- one larger graph/wave/form/device visualization stage;
- a single-line capability rail for CAS, Graph, Sound, Form, and Prototype;
- a restrained Workbench call to action.

The widget preserves reduced-motion behavior and continues to work when the backend is unavailable, while exposing backend connection state when configured.
