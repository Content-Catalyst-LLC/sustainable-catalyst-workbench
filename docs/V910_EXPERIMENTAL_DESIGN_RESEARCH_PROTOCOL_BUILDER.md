# Workbench v9.1.0 — Experimental Design & Research Protocol Builder

Formal protocol authoring and content-addressed protocol records bound to v9 scientific studies. The builder captures hypotheses, variable roles, experimental arms, sampling, randomization/blinding, measurement, analysis, stopping criteria, preregistration metadata, and explicit execution/Core handoff plans.

Protocol completeness is not scientific validity. The release does not calculate sample size automatically, choose statistical methods, infer significance or causality, infer ethics approval, accept hypotheses, dispatch execution, or write to Platform Core automatically.
