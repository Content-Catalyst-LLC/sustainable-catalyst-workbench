# Workbench v5.1.0 — Universal Mathematics & CAS Engine Foundation

Version 5.1.0 begins the TI-Nspire capability-gap closure by establishing a secure symbolic mathematics core rather than adding another isolated calculator.

The release adds a restricted expression parser, exact symbolic arithmetic, simplify/expand/factor, numeric evaluation, equation/system solving, differentiation, integration, limits, series, substitution, canonical content-hashed math objects, a dedicated Mathematics Studio, backend health visibility, and explicit no-arbitrary-code boundaries.

The existing v5.0.0 Integrated Platform remains intact. v5.1.0 is additive and raises the canonical Workbench plugin/backend version to 5.1.0.

Next planned build: **v5.2.0 — Interactive Graph Mathematics**, linking equations to Cartesian, parametric, polar, implicit, contour, and 3D representations with live parameters.
