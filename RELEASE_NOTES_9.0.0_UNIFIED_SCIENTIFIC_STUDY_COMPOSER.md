# Workbench v9.0.0 — Unified Scientific Study Composer

Introduces a top-level, content-addressed scientific study object that binds research questions and protocols to Workbench project assets, parameter references, execution jobs, immutable v8.10 analysis snapshots, researcher-authored findings, and immutable v8.11 publication/evidence packages. Stage readiness is explicit and descriptive only; it is not scientific-validity certification. Platform Core remains the governed research authority and Core handoff remains plan-only.
