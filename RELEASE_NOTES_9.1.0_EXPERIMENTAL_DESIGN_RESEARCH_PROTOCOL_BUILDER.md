# Workbench v9.1.0 — Experimental Design & Research Protocol Builder

Workbench v9.1.0 adds formal, content-addressed research protocol objects bound to v9 scientific studies. Researchers can explicitly define hypotheses, variable roles, experimental arms, sampling plans, randomization/blinding, measurement plans, analysis plans, stopping criteria, preregistration metadata, and amendments.

The release adds explicit protocol-to-execution and Platform Core planning surfaces. Neither performs automatic dispatch. Protocol readiness reports completeness only; it does not certify scientific validity, infer ethical approval, calculate sample size automatically, select statistical methods, infer causality/significance, or accept/reject hypotheses.
