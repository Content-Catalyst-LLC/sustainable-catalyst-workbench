# Workbench v10.0.0 — Scientific AI Engineering Runtime Foundation

Workbench v10 begins the AI engineering phase after the certified v9 scientific research lifecycle. v10.0.0 introduces content-addressed AI engineering experiment specifications, explicit model/provider references, dataset lineage bindings, deterministic training and inference configuration, environment pinning, resource budgets, evaluation hooks, neutral execution plans, and Platform Core plan-only handoffs.

## Boundaries

The foundation does not automatically download models, launch training, perform inference, call external providers, run arbitrary code, select a preferred model, infer scientific validity, or dispatch/persist governed Platform Core objects. Concrete execution adapters are intentionally deferred to later v10 releases.
