# Workbench v9.8.0 — Cross-Study Comparison & Meta-Analysis Workspace

Adds a researcher-controlled cross-study quantitative synthesis layer over explicit study effect records.

## Capabilities
- explicit effect records with source lineage
- identity, natural-log ratio, and Fisher-z normalization
- inverse-variance fixed-effect pooling
- DerSimonian–Laird random-effects pooling
- Q, I², tau² and heterogeneity p-value diagnostics
- subgroup meta-analysis
- leave-one-out sensitivity
- pairwise effect differences
- content-addressed immutable records
- forest/funnel/subgroup/influence visualization plans
- plan-only Platform Core handoff

## Boundaries
Workbench does not decide study comparability, choose the preferred pooling model, infer causal conclusions, declare scientific significance/validity, resolve publication bias, or create governed Core claims automatically.
