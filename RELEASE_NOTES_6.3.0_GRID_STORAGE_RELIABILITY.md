# Workbench 6.3.0 — Grid, Storage & Reliability Analysis

Adds seven explicit-input Energy Systems v1.6.0 operations: storage round-trip, storage state-of-charge trajectory, reserve margin, peak-demand coverage, loss-of-load event counting, energy not served, and bounded adequacy time-series analysis. No hidden defaults, automatic dispatch, outage prediction, real-grid reliability declaration, ranking, recommendation, or persistence is enabled.
