# v10.0.0 Scientific AI Engineering Runtime Foundation Map

```text
Research Project
  -> AI Engineering Experiment
      -> Model Reference
      -> Dataset Bindings
      -> Environment / Dependency Identity
      -> Training Configuration
      -> Inference Configuration
      -> Evaluation Hooks
      -> Resource Budget
      -> Content-Addressed Experiment Record
          -> Neutral Execution Plan
          -> Platform Core AI Experiment Plan
```

Execution is not automatic in v10.0. The release establishes stable contracts for local models, Workspace ML runtimes, OpenAI-compatible/provider APIs, Hugging Face-compatible sources, and custom adapters while preserving researcher control and provenance.
