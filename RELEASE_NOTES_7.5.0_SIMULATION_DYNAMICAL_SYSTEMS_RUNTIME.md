# Workbench v7.5.0 — Simulation & Dynamical Systems Runtime

Promotes Workbench simulation and dynamical-systems capabilities into a canonical runtime above v7.4.

## Capabilities
- Canonical scalar, linear state-space, ODE/IVP, and bounded digital-twin simulation specifications.
- Normalized state trajectories and deterministic content hashes.
- Threshold-crossing event detection with rising/falling direction.
- Continuous linear-system eigenvalue stability diagnostics and bounded model-specific diagnostics.
- Explicit bounded parameter sweeps with no automatic optimization.
- v7.3 dataset/variable/parameter workspace binding plans.
- v7.1 execution-object projection and Platform Core computation-lineage output plans.

## Boundaries
No arbitrary code, shell execution, automatic model selection, automatic Core dispatch/persistence, scientific-validity certification, or general stability proof is authorized.
