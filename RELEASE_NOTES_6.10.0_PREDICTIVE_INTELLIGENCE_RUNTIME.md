# Sustainable Catalyst Workbench v6.10.0
## Predictive Intelligence Runtime Integration

Workbench v6.10.0 adds specialist predictive execution aligned to Platform Core's predictive-intelligence and visual-predictive registries.

### Added
- deterministic naive, drift, mean, moving-average, and linear-trend forecasting
- residual-based probabilistic interval generation
- expanding-window rolling-origin backtesting with MAE, RMSE, and MAPE
- binary probability calibration with Brier score, log loss, reliability bins, and expected calibration error
- Core model, target, forecast-run, probabilistic-forecast, calibration-evidence, and visual-predictive registration plans
- v6.7 lineage and v6.9 visual-predictive integration boundaries

### Boundaries
Workbench fits and executes predictive calculations. Platform Core records predictive models, provenance, forecast/calibration evidence, packages, and visual predictive semantics. Core does not automatically execute, rank, select, persist, or determine truth.

No database migration is required.
